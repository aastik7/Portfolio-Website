## 🎯 **About This Project**

This portfolio website represents the culmination of modern web development practices, featuring stunning 3D animations, smooth interactions, and a fully functional contact system. Built with performance and user experience in mind, it showcases both technical expertise and creative design sensibility.

## ✨ **Key Features**

### 🎨 **Visual Excellence**
- **3D Interactive Models** - Immersive Three.js animations and models
- **Smooth Animations** - Framer Motion powered transitions and effects
- **Responsive Design** - Pixel-perfect across all devices and screen sizes
- **Modern UI/UX** - Clean, professional interface with attention to detail

### 🛠️ **Technical Highlights**
- **Dynamic Typewriter Effect** - Eye-catching text animations on the hero section
- **Functional Contact Form** - EmailJS integration for real email submissions
- **Form Validation** - Client-side validation with error handling
- **Performance Optimized** - Fast loading times and smooth interactions
- **SEO Ready** - Optimized meta tags and semantic HTML structure

### 📱 **User Experience**
- **Intuitive Navigation** - Smooth scrolling and easy-to-use interface
- **Loading States** - Professional loading indicators and feedback
- **Error Handling** - Graceful error management and user feedback
- **Accessibility** - Built with web accessibility standards in mind

## 🚀 **Quick Start**

### Prerequisites
- **Node.js** (v16+ recommended)
- **Yarn** or **npm**

### Installation

```bash
# Clone the repository
git clone https://github.com/aastik7/Portfolio-Website.git

# Navigate to project directory
cd Portfolio-Website

# Install dependencies
yarn install
# or
npm install

# Start development server
yarn dev
# or
npm run dev
```

### Development Commands

```bash
yarn dev      # Start development server
yarn build    # Build for production
yarn preview  # Preview production build
yarn deploy   # Deploy to GitHub Pages
yarn lint     # Run ESLint
```

## 📧 **Contact Form Setup**

The portfolio includes a fully functional contact form powered by **EmailJS**:

1. **Create EmailJS Account** at [emailjs.com](https://emailjs.com)
2. **Set up Email Service** (Gmail, Outlook, etc.)
3. **Create Email Template** with variables: `{{from_name}}`, `{{from_email}}`, `{{message}}`
4. **Update credentials** in `src/components/Contact.jsx`

## 🌐 **Deployment**

This project is configured for **GitHub Pages** deployment:

```bash
yarn deploy
```

The site will be available at: `https://yourusername.github.io/Portfolio-Website/`
